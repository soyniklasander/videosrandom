# 🎬 Reproductor de Videos

Una página web simple y elegante para reproducir videos con HTML5, CSS y JavaScript.

## Características

- 🎥 Reproductor de video HTML5 con controles nativos
- 📋 Lista de videos interactiva
- 🎨 Diseño moderno y responsivo con gradiente
- 🔄 Cambio de videos dinámico sin recargar la página
- ▶️ Auto-reproducción del siguiente video cuando termina el actual
- 📱 Totalmente responsivo para dispositivos móviles

## Cómo usar

1. Abre el archivo `index.html` en tu navegador web
2. El primer video se cargará automáticamente
3. Haz clic en cualquier video de la lista para reproducirlo
4. Usa los controles del reproductor para pausar, ajustar volumen, pantalla completa, etc.

## Estructura del proyecto

```
.
├── index.html          # Página principal con HTML, CSS y JavaScript
├── videos/             # Directorio con los archivos de video
│   ├── VIDEO BH1.mp4
│   ├── VIDEO BH2.mp4
│   ├── VIDEO BV1.mp4
│   └── VIDEO BV2.mp4
└── README.md           # Este archivo
```

## Tecnologías utilizadas

- HTML5 (Video API)
- CSS3 (Flexbox, Grid, Gradientes)
- JavaScript (ES6+)

## Vista previa

El reproductor incluye:
- Título y descripción del video actual
- Reproductor de video con controles completos
- Galería de videos disponibles
- Indicador visual del video activo
- Diseño con gradiente púrpura moderno
